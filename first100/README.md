# First 100 CrossFit.com WODs

Static GitHub Pages page for `lifeboatplanner.com/first100`.

This version is self-contained: `data.js` embeds the full verbatim entries for the corrected first 100 days of CrossFit.com programming, from 10 Feb 2001 through 20 May 2001 inclusive. The extra 21 May 2001 entry is intentionally excluded.

## Files

- `index.html` — page shell and stats table
- `styles.css` — minimal styling
- `data.js` — embedded stats, date list, and all 100 full entries
- `script.js` — rendering/search/expand-collapse behavior

## Deploying on GitHub Pages

Copy the files into the folder that should serve `/first100`, for example:

```text
/first100/index.html
/first100/styles.css
/first100/data.js
/first100/script.js
```

The Lifeboat App Store link appears at the top and bottom of the page.
